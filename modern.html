All About Web Browsers

Usage

There are various reasons different users use different types of web browsers. Chrome has consistently been the most widely used for more than a decade, though it is not the only option in the public consciousness.

Standards

Different browsers may have different options as far as extensions, themes, and compatibility with outside software, but there are features that are standard for all web browsers, such as bookmarks, browsing history, downloads, and keyboard shortcuts.

Other widely-used standards in modern web browsers include compatibility with JS (JavaScript) and CSS (Cascading Style Sheets) to further customize HTML webpages. Adobe Flash Player was a huge development for interactive webpages alongside the development of web browsers from the 90’s to the 2010’s, but has since become defunct after the main features of Flash became integrated into HTML5.

Features

Modern web browsers also offer useful features like built in security and syncing tabs and bookmarks across instances by allowing the user to make an account and log in on multiple devices.

There are also many accessibility features such as voice search and screen reading.

Old vs New

Opera GX is a browser that is developed for and marketed towards gamers. Apple Safari is known for its security and is uniquely developed for iOS. Firefox and Chrome are both known for their extensions, which are add-on features written by 3rd parties to extent the functionality of the browser. DuckDuckGo and Tor are both known for their security and privacy, taking precautions to prevent cookie storage and other trackers.

Current Events

There seems to be a growing anti-Google and anti-Windows sentiment in regards to the tracking and surveillance that has been becoming more prevalent in the past few years. Targeted advertising is miniscule in comparison to the amount of information that is being gathered on users, stored in profiles, and being offered to the government.

There is also a public split on AI usage and development, though the browsers that offer AI features also offer the option to turn it off.

Future

There are predictions regarding future browsers’ compatibility with 3D files and virtual / integrated reality, as well as video call quality, translation features, and other integrations.

The United States ranks as the lowest in confidence of being to able to effectively regulate AI usage responsibly.

Depending on the direction of AI and surveillance, I can see browsers like DuckDuckGo and Firefox becoming more popular for the average user, and Tor becoming more popular for those who are a little bit more technically literate.
