About

>

I am a dual-major (BSA Digital Animation + BSIT Undecided Focus) at KSU and also work full time in the screenprinting industry running an HP Indigo Press as well as other industrial printers. I have an interest in programming and other types of problem-solving, though my hobbies are usually more art related. This project has been a great way of re-learning HTML & CSS for me, as I have not revisited a lot of these concepts since I took Web Design in High School.

I chose to focus on Web Browsers for this project because the topic is so broad and there have been constant developments of Web Browsers and how they function ever since they were first created. I thought it would be enough information to stay interesting throughout the semester.

The image on the left is an actual newspaper collage self portrait I did for another class.

This website is a project for IT3203. More information can be found at the class GitHub.
