All About Web Browsers

Abstract

An exploration on the history and development, modern instances and features, and current trends of web browsers.



Key Terms

Word Meaning / Definition
Browser / Web Browser Program that retrieves and displays pages from the Internet, as well as allowing for navigation of other pages via hyperlinks
Hyperlink A digital reference point to other data, typically in the form of another webpage
IP address Internet Protocol address. A number that is unique to every device connected to a computer network,. Acts as a location marker for data requests / responses.
DNS Domain Name System. A way for IP addresses to be read as URLs to be readable to humans.
TCP Transmission Control Protocol. The way that packets are sent and received via the Internet.
HTTP(S) Hypertext Transfer Protocol (Secure)
URL Uniform Resource Locator
Cookie Data preferences that are stored user/client - side
Extension / Add-on Custom software tools and/or plugins that change how a browser behaves
