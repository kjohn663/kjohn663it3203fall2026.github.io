Invention

The first web browser, WorldWideWeb, was created in 1990 and released in 1991 by Tim Berners-Lee at CERN (European Organization for Nuclear Research) for the NeXT Computer.

The Browser Race

The years following saw a boom in various projects as people tried making their own web browsers with different features. MidasWWW in 1992 by Tony Johnson was based on Motif/X and allowed for viewing PostScripts. Cello in 1993 by Thomas R. Bruce had graphics compatibility.

This boom in browser development inspired Mosaic, which was the first full graphical browser with an intuitive user interface and compatibility with multimedia images. Mosaic was released in 1993 by NCSA (National Centre for Supercomputing Applications).

For the Public

The first public web browser was released in 1994 by Marc Andreessen after he left NCSA to develop Netscape. IBM released the WebExplorer for the OS/2 Warp operating system in 1995. Windows released the first version of Internet Explorer, included with Windows95 also in 1995.

Origins of Big Names

Opera Software released the Opera browser in 1996. Various developments continued from multiple companies and programmers throughout 1996 and 97.

In 1998, Netscape made its code open-source, which led to the development of Mozilla (later to become Mozilla Firefox).

Apple did not release the first browser for the Macintosh system until 2003, Safari.

Google Chrome was released in 2008, and continues to be the most ppularly used browser today.

The Tor web browser began development in 2008 and became more widely known after the Snowden disclosures in 2013.

Features Added

Throughout all of these browsers, there was consistent development of compatibility with multimedia elements and different file types, as well as newer and broader versions of the HTML programming language used to display these elements.
